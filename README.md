# Report_A_M6_W1

Little GP Champions Level A, Month 6, Week 1 report project: a playful, athlete-themed, mobile-friendly 20-question kindergarten quiz with four sections—Phonics, Literacy Key Sentences, Reading, and Math.

## Use it

Open `index.html` in any web browser. No installation or internet connection is required for the quiz itself (the page uses a Google font when online and falls back gracefully when offline).

## Edit the weekly lesson

Open `script.js` and edit the `questions` list near the top. Keep five questions for each section. Each question has two choices, and `answer: 0` means the first choice is correct (`answer: 1` means the second).

## Publish with GitHub Pages later

1. Create a new GitHub repository.
2. Upload all four files in this folder.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

GitHub will provide your public website link.
